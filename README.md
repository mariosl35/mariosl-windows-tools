# MARIOSL Windows Tools

A lightweight, modular Windows 11 tweaking and maintenance tool focused on **privacy, performance, debloating, and control**.

> **Pre-alpha — `v0.1.0-pre-alpha`**
>
> Expect bugs, incomplete features, and breaking changes.

## Features

* Windows AppX removal
* Registry tweaks
* Windows service configuration
* Windows AI / Copilot / Recall controls
* Automatic snapshots and rollback
* Optional System Restore point
* JSON-based tweak definitions

## Usage

1. Download the latest release.
2. Extract the ZIP.
3. Run `mariosl-windows-tools.cmd`.
4. Accept the UAC prompt.
5. Select the tweaks you want to apply.

**Windows 11 only. Administrator privileges are required.**

## Safety

MARIOSL Windows Tools is designed to make changes reversible where possible, but it is still system-modification software.

**Do not use pre-alpha releases on critical systems. Review what a tweak does before applying it.**
